# Slides

Skills for slide decks: what goes on each slide, how it looks, and the script that goes with it.

## Model-invoked

Rich trigger phrasing so the agent can reach for them automatically (also usable on request).

- **[one-idea-slides](./one-idea-slides)** - Turn a talk into a calm PowerPoint deck: one idea a slide on a dark or light page, big numbers in one accent colour, sourced claims, and the whole script with timings in the presenter notes. Builds from one JSON file, checks it, and previews every slide as a PNG.
